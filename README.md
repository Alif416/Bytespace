# ByteSpace

ByteSpace is a course marketplace landing page built with React, Vite, and Tailwind CSS.

## Tech stack

- React 19 + Vite
- Tailwind CSS v4
- JavaScript (no TypeScript)

## Getting started

```bash
npm install
npm run dev
```

## Project structure

Reusable UI pieces live under `src/components`, with decorative/background
elements grouped in `src/components/decor` and icons in `src/components/icons`.
